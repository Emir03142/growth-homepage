# 我的成长主页

个人学习记录与技能展示网页，用于记录大学期间的学习过程、做过的项目和遇到的问题。

## 在线访问

<!-- 开启 GitHub Pages 后，把下面的链接换成你的真实地址 -->
https://emir03142.github.io/growth-homepage/

## 页面说明

- `index.html`：关于我，包括个人介绍、学习方向和接下来的计划。
- `learning.html`：学习记录，按时间记录学过的内容、遇到的问题和解决情况。
- `skills.html`：技能与项目，包括 C 语言和 Python 的代码示例、项目作品说明、联系方式和留言表单。
- `style.css`：所有页面共用的样式文件。

## 技术栈

HTML、CSS、JavaScript，不依赖任何框架或第三方库。

## 运行方式

1. 下载或克隆本仓库到本地。
2. 双击 `index.html`，或用浏览器打开它即可查看。
3. 也可以直接访问上面的在线地址。

## 功能说明

- 三个页面之间通过顶部导航相互跳转。
- 技能页的留言表单会检查姓名、邮箱和留言内容是否为空，邮箱格式是否正确。本页面没有后端，提交后内容不会被发送到任何服务器。

## 后续更新

每学完一个新内容，就在 `learning.html` 中补充一条记录，并更新页面底部的日期。

## 隐私说明

本页面不包含手机号、家庭住址或身份证号等敏感信息。
